# Tugas #6 Mobile Developer - Sahabat Alfary

Proyek aplikasi mobile pembelajaran (Sahabat Alfary) yang diimplementasikan menggunakan Flutter berdasarkan desain UI/UX PBL UAS.

## 📌 Deskripsi Fitur & Arsitektur
- **Clean Architecture & Modular:** Pemisahan struktur kode yang jelas antara UI (`screens/`), State Logic (`providers/`), dan Data Model (`models/`).
- **Advanced UI:** Menggunakan tata letak lanjutan seperti `CustomScrollView`, `SliverAppBar`, serta `Stack` untuk card promosi.
- **Global State Management:** Menggunakan **Provider** untuk mengelola data lintas layar (nama user dan status membership Free/PRO yang langsung ter-update di Home maupun Dialog).
